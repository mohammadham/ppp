# پروژهٔ لاتک پایان‌نامه دانشگاه بیرجند

این پروژه متن بخش‌های تحویلی را بدون بازنویسی به لاتک منتقل می‌کند. فایل‌های `sources/` نسخهٔ بایتی دست‌نخوردهٔ ورودی‌ها هستند. خطاهای علمی، عددی، املایی، شماره‌گذاری و فرمول‌های آسیب‌دیده به صورت حدسی اصلاح نشده‌اند؛ گزارش‌ها بیرون از متن پایان‌نامه‌اند.

## استفاده
1. کل ZIP را استخراج کنید؛ فونت‌ها و تصاویر باید همراه فایل‌های tex باشند.
2. فایل `metadata.tex` را فقط برای مشخصات شخصی و اطلاعات جلد تکمیل کنید.
3. برای کار روی پایان‌نامه `main.tex` را در ویرایشگر لاتک باز کنید و موتور **XeLaTeX** را انتخاب کنید.
4. برای به‌روزرسانی فهرست‌ها دو یا سه بار کامپایل کنید. فرمان: `latexmk -xelatex main.tex`.
5. برای خروجی مستقل فصل اول، `chapter-01.tex` را از ریشه پروژه اجرا کنید؛ برای سایر فصل‌ها شماره را تغییر دهید. فایل داخل پوشه `chapters` به تنهایی پیش‌گفتار ندارد.

## وابستگی‌ها
TeX Live همراه xetex، xepersian، bidi، fontspec، extreport، geometry، amsmath، amssymb، graphicx، array، longtable، booktabs، pdflscape، titlesec، setspace، needspace، tcolorbox، caption و hyperref. در Debian/Ubuntu بسته‌های `texlive-xetex texlive-lang-arabic texlive-latex-extra texlive-fonts-recommended latexmk` کافی‌اند. فونت‌ها با مسیر نسبی از پوشه `fonts` بارگیری می‌شوند و نصب سراسری لازم نیست.

## ساختار
- `main.tex`: پایان‌نامهٔ یکپارچه.
- `chapter-01.tex` تا `chapter-05.tex`: ورودی‌های مستقل هر فصل.
- `chapters/`: متن لاتک فصل‌ها؛ نام/بازه خطوط مبدأ بالای بلوک‌ها ثبت شده‌اند.
- `frontmatter/` و `metadata.tex`: صفحات آغازین و مشخصات جلد.
- `references.tex`: فهرست منابع یکتا؛ متن مدخل‌ها از ورودی‌ها گرفته شده است.
- `appendices.tex`: پیوست‌ها، کدهای پایتون و جدول NIST.
- `figures/`: تصویرهای مورد استفاده، بدون تغییر فایل تصویری.
- `fonts/`: فونت‌ها و گزارش منشأ آن‌ها.
- `template/`: DOCX قالب اصلی و نشان‌های استخراج‌شده از آن.
- `sources/`: همه ورودی‌ها از جمله نسخه‌های جایگزین؛ فایل‌های بدون `(1)` مبنای بخش‌ها هستند.
- `reports/`: گزارش هر فصل، نگاشت منابع، مغایرت‌های مبدأ و هش‌های کنترل انتقال.
- `tools/`: مبدل قابل بازاجرا با Python استاندارد؛ بدون وابستگی به مدل زبانی.

## بازتولید
`python tools/frontmatter.py` و سپس `python tools/build.py` همه فصل‌ها را بازتولید می‌کنند. برای فقط یک فصل از `python tools/build.py --chapter 3` استفاده کنید. بازتولید فایل‌های تولیدشده را جایگزین می‌کند؛ اگر مستقیماً texها را ویرایش کرده‌اید پیش از اجرای مجدد از آن‌ها نسخه بردارید.

## مهم
قبل از استفاده نهایی `reports/source-issues.md` و `reports/template-rules.md` را بخوانید. ارجاع [11] بدون مدخل، تفاوت شماره‌گذاری منابع فصل اول، شکل ۳-۲ تکراری، فرمول‌های آسیب‌دیده مبدأ و طول چکیده‌ها نیازمند تصمیم نویسنده‌اند. هیچ منبع یا اصلاح محتوایی برای رفع این ابهام‌ها ساخته نشده است.

خروجی درخواستی فقط پروژهٔ لاتک است؛ PDF داخل ZIP قرار نمی‌گیرد. دانلود ZIP در هر درخواست از پوشهٔ فعلی پروژه ساخته می‌شود و به فایل فشردهٔ قدیمی اشاره نمی‌کند.
