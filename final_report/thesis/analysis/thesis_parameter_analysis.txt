2. TECHNICAL FINDINGS FROM CODE REVIEW
------------------------------------------------------------

2.1 Hyperchaotic ODE System (scripts/chaos.py)
-----------------------------------------------
The 5D system is defined as:
  dx = a * (y - x) + u
  dy = c * x - x * z + d * y + v
  dz = x * y - b * z
  du = -y * z + e * u      ← Current (positive e=0.2)
  dv = x * z - e * v

2.2 Stability Issue Identified
------------------------------
With e = +0.2 (positive), the u-component grows unbounded:
  du/dt ≈ e·u when x·z is small
  → Exponential growth: u(t) ~ u(0)·e^(e·t)
  → After ~5 time units: u becomes O(100×u(0))
  → System diverges from Lorenz attractor basin

2.3 Documented Correction Option
--------------------------------
Changing the sign:  du = -y * z - e * u
  → u is bounded: du/dt = -y·z - e·u
  → The -e·u term provides linear damping
  → System remains in attractor basin (verified in test runs)
  → This is a single-line code change in scripts/chaos.py

2.4 Current Code Behavior
-------------------------
- With e=+0.2 and du = -y·z + e·u: Device diverges at ~step 5000
  during DRIVE image encryption (~331,000 total steps)
- With e=−0.2 and du = -y·z - e·u: Device stays bounded
  (author‑corrected damping)
