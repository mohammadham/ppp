# نسخه مقاله ژورنالی

## ساختار پوشه

این پوشه شامل نسخه‌ی فشرده و ژورنالی مقاله است که از پایان‌نامه استخراج شده است.

### فایل‌ها:

1. **article_full.md** - متن کامل مقاله به فرمت Markdown
   - چکیده (فارسی و انگلیسی)
   - مقدمه
   - مروری بر ادبیات
   - روش پیشنهادی
   - طرح آزمایش‌ها
   - نتایج مورد انتظار
   - جمع‌بندی و نتیجه‌گیری
   - منابع

## ویژگی‌های مقاله ژورنالی

- **فشرده‌سازی محتوا:** محتوای ۵ فصل پایان‌نامه در ۶ بخش مقاله‌ای جمع‌آوری شده
- **لحن آکادمیک:** مناسب برای ارائه به ژورنال‌های علمی
- **ارجاعات APA:** با ۶ منبع معتبر
- **دوزبانه:** چکیده به هر دو زبان فارسی و انگلیسی
