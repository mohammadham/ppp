۳-۴. سیستم غیرخطی ابرآشوبی ۵ بعدی، حل عددی و تولید کلیدهای رمزی

برای تضمین آنتروپی آرمانی (H(m) ≈ 8.0)، شکستن کامل همبستگی مکانی پیکسل‌های مجاور، مقاومت در برابر حملات بازسازی فضای فاز (Phase Space Reconstruction Attack) و ایجاد فضای کلید عظیم فراتر از 2^520، سیستم امنیتی پیشنهادی از یک سیستم غیرخطی ابرآشوبی ۵ بعدی پیوسته جدید استفاده می‌نماید [1]. در مقایسه با نگاشت‌های آشوبی کم‌بعد سنتی (نظیر نگاشت لوجستیک ۱ بعدی یا نگاشت هنون ۲ بعدی) که به دلیل سادگی ساختار ریاضی در برابر حملات تحلیل تفاضلی و CPA آسیب‌پذیر هستند، سیستم ۵ بعدی به دلیل دارا بودن بیش از یک توان نمای لیاپانوف مثبت (Multiple Positive Lyapunov Exponents: λ1, λ2 > 0)، پیچیدگی دینامیکی فوق‌العاده بالا و رفتار شبه‌تصادفی غیردوره‌ای، بالاترین سطح محرمانگی را برای تصاویر پزشکی فراهم می‌سازد [1, 3, 10].

۳-۴-۱. فرمول‌بندی ریاضی دستگاه معادلات دیفرانسیل ۵ بعدی
دستگاه معادلات دیفرانسیل حالت پیوسته سیستم ۵ بعدی ابرآشوبی شامل ۵ متغیر حالت (x, y, z, u, v) و ۷ پارامتر کنترلی غیرخطی (a, b, c, d, k, h, w) به صورت زیر فرمول‌بندی می‌گردد [1]:

که در آن، شرایط اولیه سیستم (x0, y0, z0, u0, v0) مستقیماً از خروجی نرمال‌سازی‌شده تابع هش SHA-256 (محاسبه‌شده از ویژگی‌های آماری ROI در بخش ۳-۳) تغذیه می‌شوند. این امر وابستگی ۱۰۰ درصدی توالی‌های رمزی حاصله به تصویر واضح ورودی را تضمین می‌نماید.

برای تجسم رفتار دینامیکی، پیچیدگی فضای فاز و اثبات وجود جاذبه غریب (Strange Attractor)، تصوير پرتره فاز ۳ بعدی حاصل از تصویر کردن متغیرهای حالت (x, y, z) در شکل ۳-۵ نشان داده شده است.

۳-۴-۲. حل عددی دستگاه معادلات با روش رونگه-کوتا مرتبه ۴ (RK4)
از آنجایی که معادلات دیفرانسیل سیستم ۵ بعدی پیوسته هستند، برای پیاده‌سازی دیجیتال و استخراج توالی‌های رمزی گسسته، دستگاه معادلات با استفاده از روش حل عددی رونگه-کوتا مرتبه ۴ (Runge-Kutta 4th Order - RK4) با گام زمانی یکنواخت h = 0.001 حل می‌گردد.

برای حذف اثرات گذرا (Transient Effect) و اطمینان از قرارگیری کامل سیستم در فاز ابرآشوبی پایدار، N0 = 1000 نمونه اولیه تولیدشده از توالی حذف گردیده و مابقی نمونه‌ها به تعداد لازم برای ابعاد تصویر (M = W x H) استخراج می‌شوند.

۳-۴-۳. گسسته‌سازی و استخراج کلیدهای رمزی ۸ بیتی (K1 تا K5)
توالی‌های پیوسته اعشاری حاصل از حل عددی (x_i, y_i, z_i, u_i, v_i) از طریق نگاشت اعشاری به اعداد صحیح ۸ بیتی در بازه [0, 255] تبدیل می‌شوند تا ۵ ماتریس کلید رمزی K1, K2, K3, K4, K5 شکل گیرند:

- K1(i) = floor( |x_i| * 10^14 ) mod 256
- K2(i) = floor( |y_i| * 10^14 ) mod 256
- K3(i) = floor( |z_i| * 10^14 ) mod 256
- K4(i) = floor( |u_i| * 10^14 ) mod 256
- K5(i) = floor( |v_i| * 10^14 ) mod 256

کلیدهای K1 و K2 جهت تعیین الگوی آشفته‌سازی زیگ‌زاگی و کلیدهای K3, K4, K5 جهت انتخاب پویای قواعد کدگذاری DNA و اجرای عملگرهای انتشار DNA XOR مورد استفاده قرار می‌گیرند. 

الگوریتم گام‌به‌گام راه‌اندازی سیستم ۵ بعدی و استخراج کلیدها در شبه‌کد ۳-۲ ارائه شده است.

[شبه‌کد ۳-۲: راه‌اندازی سیستم ابرآشوبی ۵ بعدی با حل عددی RK4 و گسسته‌سازی کلیدهای رمزی]
--------------------------------------------------------------------------------
Input  : Initial Values (x0, y0, z0, u0, v0), Image Dimensions W, H, Step Size h = 0.001, N0 = 1000
Output : 8-bit Key Matrices K1, K2, K3, K4, K5 of size W x H

1. Total_Steps = N0 + (W * H)
2. Initialize State Vector: X = [x0, y0, z0, u0, v0]^T
3. For n = 1 to Total_Steps:
     Compute k1 = f(X)
     Compute k2 = f(X + (h/2)*k1)
     Compute k3 = f(X + (h/2)*k2)
     Compute k4 = f(X + h*k3)
     X_next = X + (h/6) * (k1 + 2*k2 + 2*k3 + k4)
     Store X_next to Raw_Stream[n]
     X = X_next
4. Discard first N0 transient samples: Valid_Stream = Raw_Stream[N0+1 : Total_Steps]
5. For i = 1 to (W * H):
     K1[i] = floor( abs(Valid_Stream[i].x) * 10^14 ) mod 256
     K2[i] = floor( abs(Valid_Stream[i].y) * 10^14 ) mod 256
     K3[i] = floor( abs(Valid_Stream[i].z) * 10^14 ) mod 256
     K4[i] = floor( abs(Valid_Stream[i].u) * 10^14 ) mod 256
     K5[i] = floor( abs(Valid_Stream[i].v) * 10^14 ) mod 256
6. Reshape K1, K2, K3, K4, K5 into W x H matrices
7. Return K1, K2, K3, K4, K5
--------------------------------------------------------------------------------
